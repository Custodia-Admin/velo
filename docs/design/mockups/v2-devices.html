Pairing the handlebars

  1. Pair each side on its own. Chrome lists both as "Zwift Ride".
  2. Velo buzzes the one it just connected, so you can feel which side it was.
  3. If a side stays quiet, press a button on it and try again.

On an iPad or iPhone? Browsers there can't pair Bluetooth. You can still ride with the demo rider, or use Chrome on the laptop or an Android tablet.
